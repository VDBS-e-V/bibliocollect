# BiblioCollect

Aktueller Entwicklungsstand: **T4 v0.5.0 – Circulation-Grundworkflow**.

BiblioCollect ist die modulare Schulbibliothekssoftware des VDBS e. V. auf Laravel 13. T0 Foundation, T1 Berechtigungen/Surfaces sowie T2 Identity/Patrons/School sind abgeschlossen. T3 hat den Katalog in kleinen, getrennten Schritten aufgebaut. T4 startet mit Ausleihe und Rückgabe auf einem zentralen Regelkern.

Siehe `docs/PROJECT_STATUS.md` für den aktuellen fachlichen Stand und `docs/NEXT_STEPS.md` für die nächsten Entwicklungsschritte.
